# Project Instructions: The County-Confederal System

## Project Scope & Constraints

- This repository is a purely text-based systems-design thought experiment (Markdown files only).
- There is no programming language, code compilation, or build process. Never attempt to compile or build.

## Document Architecture & Conventions

- **Master Index:** Refer to `README.md` for the subsystem directory (CON-01 through OPS-01) and reading order.
- **Cross-References:** Maintain consistent cross-referencing between files using their Subsystem IDs.
- **Status & Tracking:** Known design stress items and failure modes belong in `open-issues.md`. Historical change notes belong in `changelog.md`.
- **Tone & Style:** Maintain analytical, legalistic, and constitutional design rigor throughout all edits.

## Git Workflow

- **Commits are manual.** The user performs all `git commit`, `git tag`, `git push`, and branch operations personally. Never commit, tag, push, or create/switch branches unless explicitly asked to do so for a specific task.
- **Leave the working tree ready.** Make edits and stop; report what changed so the user can review and commit.
