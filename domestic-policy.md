# Domestic Policy — Consolidated Design

**Scope**: TRN-01 (Transition) + 8 domestic-policy subsystems (COM, ENV, WEL, EDU, FOD, HOU, LAB, ENR). Condensed design; each section is a summary, not a full spec.

**Universal principles** (apply to all): county is the operating unit; state = coordination + minimum standards (Art II §2.1); federal = vestigial; funding via LVT + user fees + compact assessments; no federal agencies; sortition + recall + personal liability; sunset everything; county veto + secession as backstops.

---

## 1. TRN-01: Transition & Implementation (The Vanish Protocol)

**Goal**: Dismantle the federal state in 5 years, hand authority to counties, and leave no successor.

### Phases

| Phase        | Years | Action                                                                                                                                                                                                                                                                                                                                       |
| ------------ | ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Decree**   | 0     | One dictatorial act: dissolve the old order and promulgate the Constitution for ratification. Abolish executive branch, Fed, income/payroll/corporate tax, federal LE, military command, agencies. Mint strikes coin. All federal statutes sunset-dated (5 yrs). Constitution provisional until ratified by 2,000+ counties (target Year 2). |
| **Stand-Up** | 1–2   | Counties adopt charters (ratified by referendum). Mutuals chartered. Compacts formed. Sheriffs elected. Courts seated. State AG elected; minimum standards adopted; State Courts of Appeals seated.                                                                                                                                          |
| **Cutover**  | 3–4   | Federal budget <$60M. State guards operational. Competitive currency normal. SCOTUS sortition seated. State appellate original jurisdiction active; interposition threshold (20 states) tested; state surcharge operational.                                                                                                                 |
| **Lock-In**  | 5     | All prior federal/state statutes void unless re-authorized, except staggered-sunset domains (air traffic control, drug safety, aviation safety) which remain provisional through Year 7. County charters re-ratified. State minimum standards re-adopted or lapse. Transition Trust continues (wind-down) to Year 20, then dissolves.        |

### The Vanish

1. Publish all decrees, code, data (open source).
2. Appoint county stewards by sortition (one per county, 1-year term, train successors).
3. Dissolve federal executive. Sell/repurpose federal assets.
4. Walk away. **No successor. No center. No ruler.**

### Contingencies

| Risk                             | Response                                                                                                                                                                                                                        |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **County refuses charter**       | Default charter template applies; residents may secede to adjacent county.                                                                                                                                                      |
| **State resists devolution**     | County veto + withholding assessments starves state.                                                                                                                                                                            |
| **Military refuses dissolution** | State guards + county militias outnumber federal; silo states hold title.                                                                                                                                                       |
| **Economic shock**               | Transition Trust (seigniorage + asset sales) funds 5 years; TANs provide local liquidity.                                                                                                                                       |
| **Foreign opportunism**          | Regional defense compacts activate; nuclear deterrent remains (governors' council).                                                                                                                                             |
| **Regulatory vacuum at Year 5**  | Art II §2.2 savings clause applies: common-law floor (trespass, nuisance, strict liability) with State Court of Appeals jurisdiction; staggered domains (air traffic, drug safety, aviation) remain provisional through Year 7. |

## 2. COM-01: Trade & Commerce Code

**Principle**: _Contracts are enforced locally. Interstate commerce is narrow. No federal commercial code._

| Element                   | Design                                                                                                                                                                             |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Contract law**          | County common law + UCC-adapted statute. Freedom of contract; unconscionability review.                                                                                            |
| **Interstate commerce**   | Only: prevent county trade barriers, standardize weights/measures, enforce cross-county judgments.                                                                                 |
| **Banking**               | County-chartered banks/credit unions; states may charter regional banks/credit unions with county opt-in. No federal charter, no FDIC, no OCC. Deposit insurance = private mutual. |
| **Securities**            | County/compact disclosure rules. No SEC. Fraud = county court.                                                                                                                     |
| **Standards**             | Voluntary compact standards (weights, measures, product safety). No federal mandate.                                                                                               |
| **Bankruptcy**            | County-administered (Ch. 7/13 equivalent). Student loans dischargeable. No means test.                                                                                             |
| **Antitrust**             | County/state enforcement. No federal FTC/DOJ. Corporate charter revocation for abuse.                                                                                              |
| **Intellectual property** | Patents (10-yr new grants; existing honored), copyrights (life+50 new), trademarks → county/compact registries (asset-transfer.md §8).                                             |

**Replaces**: UCC (federalized parts), SEC, CFTC, OCC, FDIC, FTC, CFPB.

### 2.1 State-Chartered Regional Bank Notes (Optional Fallback)

**Purpose**: Provide a state-scoped medium of exchange for inter-county trade where county TANs and specie are insufficient, without recreating a central bank or state monetary authority.

**Guardrails**:

- **County opt-in per bank**: A state may charter a regional bank only with the affirmative opt-in of each participating county commission. No county is compelled to join or accept its notes.
- **No state liability**: State-chartered bank notes are private obligations of the issuing bank, not state debt. The state guarantees neither redemption nor value. No state bailout, no state backstop.
- **Asset-backed only**: Notes must be backed by sound collateral (county TANs, specie, performing loans). No fractional issuance beyond the bank's own capital and reserves.
- **No legal tender**: No county, merchant, or resident is compelled to accept state-chartered bank notes at par or at all. Acceptance is purely voluntary and market-determined.
- **No state control of volume**: The state charter sets capital and collateral rules but does not set issuance quotas, interest rates, or monetary policy. The bank's note issuance is market-constrained.
- **Finite maturity**: Bank notes mature in 1–3 years from issuance, set at chartering and fixed for the life of the note. Matured notes are redeemed by the issuing bank or become worthless; they do not circulate indefinitely.
- **Regional, not statewide monopoly**: Multiple banks may be chartered within a state. No exclusive franchise. Counties may belong to multiple regional bank networks.
- **Sunset and exit**: Charters expire in 5 years unless re-authorized by the state legislature with county opt-in renewal. Participating counties may withdraw with 12 months' notice.
- **Insolvency**: Failed banks are liquidated by county courts. Note holders are unsecured creditors. No state funds cover losses.
- **Transparency**: Banks publish weekly redemption/issuance data. County treasurers may inspect collateral upon request.
- **Anti-counterfeiting**: Bank notes must include physical security features equivalent to county TAN anti-counterfeiting standards (`public-finance.md` §1.3): UV-fluorescent ink, security thread, cycling colors by series, and check-digit serial numbers. Counterfeiting bank notes is a county-level crime; interstate counterfeiting rings fall under SBI jurisdiction (`law-enforcement.md` §4).
- **No interstate circulation without compact**: Notes may not circulate beyond the chartering state's counties without a separate inter-county compact agreement.

**Expiration and redemption**:

- **Public notice**: Issuing bank publishes maturing note serials 30 days before expiration at the county courthouse and in the local paper. No central registry, no electronic notification.
- **Redemption window**: Notes may be redeemed at the issuing bank's window up to and including the maturity date. After maturity, notes are void and unredeemable.
- **Grace period**: None. Expired notes have no value and cannot be exchanged.
- **Bank insolvency**: If the issuing bank fails before maturity, note holders are unsecured creditors in county court liquidation. No state funds cover losses.
- **Market pricing**: Merchants and holders are expected to price approaching expiration and bank solvency risk into the note's market value; no county or state obligation to make holders whole for unredeemed notes.

### 2.2 Long-Term Infrastructure Authority (LTIA)

**Purpose**: Bridge the 5-year statutory sunset with 20- to 30-year capital commitments needed for rail corridors, electric grid transmission, nuclear facilities, water infrastructure, and other long-lived assets.

**Mechanism**:

- **Voluntary opt-in**: A Regional Compact may petition its member county commissions for Long-Term Infrastructure Authority (LTIA) for a named capital project. Each participating county must approve by commission resolution + majority referendum. No county is compelled to join.
- **Term**: Up to 30 years from project authorization, fixed at chartering. The compact may issue bonds, enter construction contracts, and collect assessments for the project term.
- **State surcharge pledge**: Participating counties may pledge their state infrastructure surcharge (≤2% of LVT base) for the LTIA term, subject to the same county opt-in and referendum rules.
- **Re-authorization checkpoints**: Every 5 years, member counties re-vote on continued participation. A county may withdraw with 12 months' notice; its assets and obligations revert to the county. Withdrawal does not terminate the LTIA for remaining members.
- **Grandfathering on lapse**: If re-authorization fails for the entire compact, existing project debt and construction contracts are honored to completion, but no new commitments may be made. The compact winds down the project and returns assets to counties per contribution.
- **No perpetual liability**: LTIA authority expires at the end of the project term (max 30 years). No compact may bind counties beyond the term without a new authorization cycle.
- **Relation to sunset**: LTIA operates under the Staggered Sunset Schedule (constitution.md Art VIII §2.3) as an extended-transition domain. It does not create a permanent state or compact authority.

**Cross-reference**: `infrastructure.md` §12 (full LTIA specification).

## 3. ENV-01: Environmental & Resource Management

**Principle**: _Pollution is trespass. Commons are managed by those who share them._

| Element             | Design                                                                                          |
| ------------------- | ----------------------------------------------------------------------------------------------- |
| **Air/water**       | County permits (NPDES-adapted). Watershed compacts for cross-county. Strict liability for harm. |
| **Public lands**    | State trust lands (revenue → SWF). Federal lands → states/counties.                             |
| **Minerals**        | State severance tax → SWF. County permits for extraction.                                       |
| **Climate**         | County carbon fee (if adopted). Compact coordination. No federal mandate.                       |
| **Fire/flood**      | County land use (no build in floodplain/fire zone). Compact mutual aid.                         |
| **Species/habitat** | County conservation easements (LVT-exempt). No ESA.                                             |
| **Waste**           | County landfills/recycling. Extended producer responsibility (county ordinance).                |

**Replaces**: EPA, Army Corps (regulatory), USFWS, BLM, USFS, NOAA (regulatory).

## 4. WEL-01: Social Welfare & Vulnerable Populations

**Principle**: _Welfare is mutual aid, not a federal program. Vulnerable people are county members._

| Population                  | Mechanism                                                                |
| --------------------------- | ------------------------------------------------------------------------ |
| **Unemployed**              | County unemployment mutual (26 wks @ 60% wage, employer-funded).         |
| **Disabled**                | County disability mutual (income-based, no means test).                  |
| **Elderly**                 | County pension trust + LTC mutual (healthcare.md).                       |
| **Children**                | County child welfare (mutual-funded). No foster-care-industrial complex. |
| **Homeless**                | County housing-first (LVT-funded). No criminalization.                   |
| **Mental health/addiction** | Integrated behavioral health mutual (healthcare.md). Harm reduction.     |
| **Food insecurity**         | County food bank + SNAP-equivalent (LVT-funded, no federal).             |

**Replaces**: SSA, HHS (ACF, AOA), HUD, USDA (FNS), SAMHSA.

## 5. EDU-01: Education & Credentialing

**Principle**: _Education is county-funded, parent-directed, apprenticeship-integrated. No federal DOE._

| Level               | Design                                                                                                               |
| ------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **K–12**            | County-funded (consumption tax surplus). Parent choice (public, charter, private, homeschool). No federal standards. |
| **Curriculum**      | County board (elected) + parent override. Rights education mandatory (Art VI).                                       |
| **Higher ed**       | County-chartered colleges/universities. No federal loans. Endowments taxed unless funding apprenticeships.           |
| **Apprenticeships** | County-chartered guilds (solutions.md). Apprenticeship = license.                                                    |
| **Credentialing**   | County license (universal recognition). No state boards.                                                             |
| **Research**        | County/university/private. Prize-funded (no NIH).                                                                    |

**Replaces**: DOE, federal student loans, accreditation cartel, state licensing boards.

## 6. FOD-01: Food & Agriculture System

**Principle**: _Food sovereignty is local. Safety is county-inspected. No federal farm policy._

| Element       | Design                                                                     |
| ------------- | -------------------------------------------------------------------------- |
| **Subsidies** | **Abolished**. No commodity programs, no crop insurance.                   |
| **Safety**    | County inspection (FDA-adapted). Direct-to-consumer exempt (food freedom). |
| **Trade**     | County/compact. No federal tariffs.                                        |
| **Reserves**  | County grain reserve (1-year caloric). No federal strategic reserve.       |
| **Land use**  | LVT favors productive use. No federal conservation programs.               |
| **Disease**   | County animal/plant health. Compact coordination.                          |

**Replaces**: USDA (FSA, RMA, AMS, APHIS), FDA (food), federal crop insurance.

## 7. HOU-01: Housing & Land Use

**Principle**: _Land value is taxed, not improvements. Zoning is local. Housing is abundant._

| Element            | Design                                                                        |
| ------------------ | ----------------------------------------------------------------------------- |
| **Tax**            | LVT (unimproved land only). No property tax on buildings.                     |
| **Zoning**         | County (by-right for housing). No minimum parking, no single-family mandates. |
| **Building codes** | County (performance-based). No federal codes.                                 |
| **Tenancy**        | County law (just-cause, habitability, deposit limits). No federal.            |
| **Public housing** | County housing trust (LVT-funded). Mixed-income, not concentrated.            |
| **Homelessness**   | Housing-first (WEL-01).                                                       |
| **Affordability**  | LVT + by-right + no parking minimums = supply. No subsidies needed.           |

**Replaces**: HUD, FHA, federal housing programs, federal zoning mandates.

## 8. LAB-01: Labor & Employment

**Principle**: _Work is voluntary. Safety is county-enforced. Unions are voluntary. No federal labor law._

| Element            | Design                                                                |
| ------------------ | --------------------------------------------------------------------- |
| **Wages**          | County minimum wage (if any). No federal minimum.                     |
| **Unions**         | Voluntary. No NLRA. No right-to-work laws (county choice).            |
| **Safety**         | County OSHA-adapted. Worker complaint → county inspection.            |
| **Wage theft**     | County court. Treble damages.                                         |
| **Discrimination** | County rights law (Art VI §2.8).                                      |
| **Gig work**       | County classification (contractor vs. employee). No federal ABC test. |
| **Non-competes**   | **Void** (Art VI §2.11).                                              |
| **Child labor**    | County standards (education-first).                                   |

**Replaces**: DOL (OSHA, Wage & Hour, OSHA, MSHA), NLRB, EEOC.
